# Quy trình


Implementer cung cấp:
- task/branch;
- summary;
- changed files;
- migrations/contracts;
- tests/results;
- known issues;
- artifacts.

- xác nhận không sửa trực tiếp;
- đọc requirements;
- chạy test;
- ghi accepted/changes requested;
- nêu file/line/bằng chứng.
