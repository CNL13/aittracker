# Quản lý task

Thư mục:

- `backlog/`: chưa làm.
- `active/`: đang triển khai.
- `review/`: chờ review.
- `done/`: hoàn tất.
- `future/`: P1/P2, không triển khai trong P0.
- `templates/`: mẫu.

Khi bắt đầu, di chuyển file thay vì sao chép.

Một task phải có:

- owner;
- reviewer;
- dependencies;
- requirements map;
- scope;
- allowed files;
- acceptance;
- handoff;
- review result.
